# FieldBasket

FieldBasket (formerly FarmLink Ekiti) is a mobile-first agricultural
marketplace designed to connect verified farmers in Ekiti State with
households, traders, restaurants, and other buyers.

## Initial Pilot

- Location: Ado-Ekiti, Ekiti State, Nigeria
- Backend: Python and FastAPI
- Frontend: React, TypeScript, Vite, and React Router ("Soil" design system in `frontend/src/styles/app.css`)
- Database: PostgreSQL
- ORM and migrations: SQLAlchemy and Alembic

## Initial MVP Scope

1. Farmer applications and verification
2. Farmer product listings and stock management
3. Buyer marketplace and product filtering
4. Role-aware access and administration
5. Automated tests for the core marketplace workflow

Payments, SMS, delivery operations, disputes, and payouts will be
introduced in later stages with appropriate provider integration
and testing.

## Project Structure

- `backend/` — API, database models, and backend tests
- `frontend/` — React application
- `docs/` — project requirements and technical documentation
